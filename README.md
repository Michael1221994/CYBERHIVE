## ⚡ Overview
**CYBERHIVE** is an award-winning-style interactive 3D WebGL web experience exploring the intersection of biological communication and anthropogenic compute expansion.

For over 100 million years, honeybees (*Apis mellifera*) have navigated Earth’s geomagnetic web using nanoscale magnetite crystals in their abdomens and their iconic **Waggle Dance** — an astronomical vector calculator encoding distance, solar azimuth, and solar angles into 250Hz abdominal vibrations.

With the exponential surge of gigawatt AI compute clusters, high-voltage transformer substations emit powerful low-frequency electromagnetic fields (ELF-EMF) and radio frequency interference (RFI) that dephase retinal cryptochromes, scramble antennal magnetite orientation, and misdirect foraging bees by up to 38° — posing a systemic threat to global pollination and food security.

## 🚀 Getting Started

No build step or Node dependencies required. Pure modern ES Modules:

```bash
# 1. Clone the repository
git clone https://github.com/Michael1221994/CYBERHIVE.git

# 2. Open with any local web server (e.g. VS Code Live Server or Python)
python -m http.server 8000
# or
npx serve .
```

Open `http://localhost:8000` in your browser.

## 🛠️ Tech Stack
* **Core:** Semantic HTML5, Vanilla JavaScript (ES Modules, Import Maps)
* **3D Engine:** Three.js (v0.160.0), Post-Processing EffectComposer, UnrealBloomPass
* **Audio Engine:** HTML5 Web Audio API (OscillatorNode, BiquadFilterNode, GainNode)
* **Styling:** Modern CSS (CSS Grid, Flexbox, CSS Houdini `@property`, Mask Compositing)
* **Typography:** Orbitron, Syncopate, Rajdhani (Google Fonts)
